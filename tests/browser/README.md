# 浏览器回归脚本

这些脚本通过 Chrome / Edge 的 CDP 接口执行真实交互，不是单元测试。

## 依赖

```bash
pip install websocket-client
```

## 运行

在仓库根目录：

```bash
python tests/browser/gs_015.py
python tests/browser/gs_016.py
python tests/browser/gs_018.py
python tests/browser/gs_019.py
python tests/browser/gs_020.py
python tests/browser/gs_021.py
python tests/browser/gs_022.py
python tests/browser/gs_023.py
python tests/browser/gs_024.py
python tests/browser/gs_025.py
python tests/browser/gs_026.py
```

脚本会：

- 自动探测 Edge / Chrome；也可用 `GS_BROWSER` 指定路径。
- 本地静态服务没起时自动启动 `http.server 8123`，结束后清理。
- 使用独立临时浏览器 profile，不碰日常浏览器数据。

可选环境变量：

- `GS_BROWSER`：浏览器可执行文件路径。
- `GS_BASE_URL`：默认 `http://127.0.0.1:8123/`。
- `GS_CDP_PORT`：`gs_015.py` 默认 `9351`，`gs_016.py` 默认 `9352`，`gs_018.py` 默认 `9353`，`gs_019.py` 默认 `9354`，`gs_020.py` 默认 `9355`，`gs_021.py` 默认 `9356`，`gs_022.py` 默认 `9357`，`gs_023.py` 默认 `9395`，`gs_024.py` 默认 `9367`，`gs_025.py` 默认 `9368`，`gs_026.py` 默认 `9369`。
- `GS_WIDTH`：`gs_016.py` / `gs_018.py` / `gs_019.py` / `gs_020.py` / `gs_022.py` / `gs_023.py` / `gs_024.py` / `gs_025.py` / `gs_026.py` 视口宽度；`gs_022.py` / `gs_023.py` / `gs_024.py` / `gs_025.py` / `gs_026.py` 默认 `360`，其余默认 `320`；可复跑另一宽度。
- `GS_THEME`：`gs_020.py` / `gs_025.py` / `gs_026.py`，`deep`（默认）或 `light`，用于检查两套主题下的设置卡片 / BPM 圆盘 / 调音设置。

`gs_021.py`：

- 直接调用 `js/services/webdav.js`，mock `fetch` 记录请求序列。
- 正常上传必须是 `PUT .uploading → PROPFIND 校验 → DELETE 正式文件 → MOVE 正式文件`，`Destination` 指向正式路径、`Overwrite: F`。
- PROPFIND 返回的大小与 PUT 字节数不一致时，只删除临时文件，不碰正式文件。
- MOVE 返回 409 或被 CORS 预检拦截（fetch TypeError）时，回退为 `PUT 正式文件 → PROPFIND 校验 → DELETE .uploading`，上传成功。
- MOVE 失败且回退 PUT 失败时，保留临时文件，错误提示包含“临时文件已保留”。
- 正式文件 GET 404 时，下载回退读取 `.uploading`；正式文件是半截 JSON 时，也改用完整的 `.uploading`；两者都不存在时报“云端没有找到备份文件”。
- 首个自定义端点 503 时自动换到本地端点，后续请求全部锁在该端点，避免跨端点替换。
