# 浏览器回归脚本

这些脚本通过 Chrome / Edge 的 CDP 接口执行真实交互，不是单元测试。

## 依赖

```bash
pip install websocket-client
```

## 运行

在仓库根目录：

```bash
python tests/browser/gs_015.py
python tests/browser/gs_016.py
python tests/browser/gs_018.py
python tests/browser/gs_019.py
python tests/browser/gs_020.py
```

脚本会：

- 自动探测 Edge / Chrome；也可用 `GS_BROWSER` 指定路径。
- 本地静态服务没起时自动启动 `http.server 8123`，结束后清理。
- 使用独立临时浏览器 profile，不碰日常浏览器数据。

可选环境变量：

- `GS_BROWSER`：浏览器可执行文件路径。
- `GS_BASE_URL`：默认 `http://127.0.0.1:8123/`。
- `GS_CDP_PORT`：`gs_015.py` 默认 `9351`，`gs_016.py` 默认 `9352`，`gs_018.py` 默认 `9353`，`gs_019.py` 默认 `9354`，`gs_020.py` 默认 `9355`。
- `GS_WIDTH`：`gs_016.py` / `gs_018.py` / `gs_019.py` / `gs_020.py` 视口宽度，默认 `320`；可设 `360` 复跑宽屏。
- `GS_THEME`：仅 `gs_020.py`，`deep`（默认）或 `light`，用于检查两套主题下的设置卡片。

## 当前覆盖

`gs_015.py`：

- 批量标签弹窗打开不自动聚焦、点快捷标签不回焦输入框。
- 云同步超时配置为上传 60s / 下载 30s / 元信息 12s。
- 挂起请求可取消，取消后胶囊消失、按钮恢复。
- 网络失败显示失败胶囊与“重试”，重试成功后恢复。
- 云同步底部按钮仍为“返回”。
- 同步进行中派发 `gs-cloud-exit-request`，弹出“云同步仍在进行”确认；点“继续同步”后弹窗关闭且任务仍在运行。

`gs_016.py`：

- 用 `fixtures/split-source.pdf` 建一张 3 页卡，从当前第 2 页打开拆分。
- 校验页段输入：0、超出总页仍禁用“建卡”；起始页大于结束页会自动纠正。
- 打开拆分后显示起止页 `P2` 缩略图，canvas 渲染成功、加载态隐藏、卡片在视口内。
- 点缩略图打开页码选择器，校验标题、当前阅读页按钮、页码数量、选中值与网格无溢出。
- 选择起始页 3 得到 `3–3`，选择结束页 1 得到 `1–1`；反向输入 `3 → 2` 自动变 `2–2`。
- 拆 2–3 页生成独立 PDF，新卡 2 页，原卡仍 3 页且标签继承。
- 新卡可重新打开、加书签、保存第 2 页进度。
- 图片卡不显示拆分按钮；损坏 PDF 拆分报错且不写记录。
- 320 / 360 宽拆分弹窗不横向溢出，按钮可点。

`gs_018.py`：

- 造一张 3 页 PDF 并打开阅读页，采样 5 个工具栏按钮：同排、同高 46、320 宽均宽 54 / 360 宽均宽 62，文案为「返回 / 打卡 / 存进度 / 书签 / 拆分」。
- 合成双指 `touchstart` / `touchmove` / `touchend`：距离 120→220，缩放值约 1.83，`scrollLeft/scrollTop` 随双指中点调整。
- 记录练习弹窗无改动时点遮罩直接关闭；有改动时先弹「放弃本次记录？」；点「继续编辑」保留弹窗与输入。
- 确认框没有详情时 `#dlgDetails` 计算样式为 `none`，不残留空白横框。
- 书签面板打开后派发 `gs-back-request`，只关面板，层级深度从 2 回到 1。
- 拆分弹窗 + 页码选择器两级返回：第一次只关 picker，第二次关拆分弹窗。
- 阅读页切到节拍器时原生层级归 0、阅读状态保留；切回乐谱恢复为 1。
- 阅读页返回书架、管理模式返回退出多选，两者层级深度均回到 0。
- 导入面板打开时点节拍器 Tab 不切页；真实触摸落在搜索框坐标时只关面板，搜索框不聚焦、不进入下层控件。
- 320 / 360 宽均通过；脚本最后重开阅读页并截图，便于人工复核工具栏。

`gs_019.py`：

- Web 模式无原生插件时，导入面板点「从相册选择」触发隐藏 input 回退，不报错。
- 伪造 21 个图片 File 走 Web input：只导入前 20 张，toast 追加「一次最多 20 张，已取前 20 张」。
- mock 原生 `GalleryPicker` 返回 `PICK_CANCELLED`：静默关闭面板、不新增卡片、不显示失败。
- mock 原生返回两个缓存路径，经 `convertFileSrc` + `fetch` 转成 File，复用 `handleFiles` 新增两张卡。
- 直接验证服务层：返回 `File`、MIME / 大小正确、无 base64 字段、失败计数递增、`limit` 夹在 20。
- 320 / 360 宽均通过；截图用于人工复核书架导入结果。

`gs_020.py`：

- 打开节拍器设置，校验 5 张卡片顺序：基础节奏 / 重音与反馈 / 高级练习 / 节奏型 / 音频跟练与测速。
- 拍号快捷格 8 个，不含 `8/8`，`4/4` 高亮；自定义输入 `8/8` 仍可应用。
- 11 个细分按钮都有短标签 + 小字说明，`四分` / `十·休3` 的 `title` 为完整说明。
- 定时快捷档 6 个排成一行，默认 15 高亮；点 `10` 输入框同步，手输 `7` 后无快捷片高亮。
- 闪光条 / 震动反馈归属“重音与反馈”，定时档归属“高级练习”，音频标题为“音频跟练与测速”。
- 滚到底部后关闭再打开设置，内容回到顶部。
- 320 / 360、深色 / 浅色均通过；无横向溢出，并输出顶部 / 定时卡 / 底部截图。

CI 只做 Python 语法编译；浏览器交互需要本机浏览器，仍在本地执行。
