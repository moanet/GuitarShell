## 4. 已锁定交互

- 头部保持品牌行 + Tab 行两行；Tab 仍按「乐谱 / 节拍器 / 调音器 / 记录」固定顺序切换。
- 版本胶囊仍点击检查更新；设置按钮仍打开右侧抽屉；抽屉关闭仍走 `.close`。
- 抽屉仍是右侧 80% 宽、无圆角、内容可滚动；外观 / 数据 / 云同步 / 存储 / 关于顺序不变。
- 44 热区只通过透明伪元素或输入框真实高度实现，不改变按钮视觉尺寸与布局位置。
