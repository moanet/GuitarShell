## 1. 目标

本轮集中处理节拍器的布局、色块反馈、拍号推测与练习记录闭环：

1. 重排节拍器主界面：设置移到左下、TAP 向中心收拢、练习 HUD 下移。
2. 新增拍点同步色块，同时承载计时 / 变速进度条。
3. 设置面板固定头部，底部“完成”改为顶部“完成”。
4. 音频测速增加拍号推测：只在设置页显示，自动填入拍号输入框，但必须手动应用。
5. 计时 / 变速自然完成后自动计入练习记录：只记先完成的一次，未完成不记。

## 2. 范围

### 做

- 节拍器底部 `[设置]` / `[TAP]` 镜像布局。
- 拍点下方动态宽度色块：同步闪动 + 计时 / 变速进度。
- 设置面板固定头部与顶部“完成”。
- 音频跟练 HUD 与练习信息一起移到圆盘下方。
- 音频分析新增拍号推测与设置页自动填充。
- 计时 / 变速自动记录，扩展记录字段与记录页展示。

### 不做

- 不删除现有 11 种细分；色块动画只处理到八分音符。
- 不把拍号推测显示到主信息栏或练习 HUD。
- 不自动应用推测拍号。
- 不记录手动停止、切 Tab、迷你节拍器抢占等未完成练习。
- 不改变音频跟练的播放、预节拍、循环与 BPM 应用主逻辑。
- 不对 5/4、7/8 等复杂拍号做强识别承诺。
- 不为三连、十六分及休止变体做色块细分闪动。

## 3. 已拍板决策

### 3.1 布局与色块

- 色块位于拍点下方，宽度跟随拍点组实际宽度；4/4 时与四个拍点左右对齐，其他拍号动态适配。
- 色块是二合一组件：拍点同步闪动条 + 计时 / 变速进度条。
- 设置放左下，TAP 向右收拢，两者同宽同高、左右镜像。
- 音频跟练 HUD 一起移到圆盘下方，保留固定高度，避免圆盘跳动。
- 色块闪动在设置页有开关；关闭后隐藏闪动。
- 计时 / 变速开启时自动显示色块；不强行改写用户的闪动开关状态。
- 闪动最多处理到八分音符；三连、十六分及其休止变体回退为每拍闪一次。

### 3.2 设置面板

- 标题在左，“完成”在右，置顶固定。
- 内容区独立滚动，删除底部“完成”按钮。
- “完成”只关闭面板，不承担保存语义；所有设置继续即时生效。

### 3.3 拍号推测

- 只在设置页音频分组显示，不进入主信息栏或 HUD。
- 分析完成后自动填入拍号自定义输入框。
- 不自动调用 `applyTimeSignature`；用户点“应用”才生效。
- 低置信度显示“不确定”，不自动填充。
- 用户已手动修改拍号输入框时，不覆盖其输入。

### 3.4 自动记录

- 计时到 0 自动停止：记录。
- 变速到达目标并保持设定小节数后自动停止：记录。
- 两者同时开启：先自然结束的记一次，只记一次。
- 手动停止、切 Tab、迷你节拍器抢占、应用退出：不记录。
- 记录字段包含：模式、实际时长、起止 BPM、日期。

## 4. 默认取舍

以下为当前默认方案，验收时可再调整：

- 计时进度条按“已用时间”从左向右填充。
- 计时与变速同时开启时，色块用上下双轨：上计时、下变速。
- 拍号推测置信度低于约 55% 时只显示“不确定”，不自动填充。
- 色块关闭且无计时/变速时，视觉隐藏但保留与拍点同高的占位（4/4 约 24px），避免圆盘高度跳动。
- 自动记录名称固定为 `节拍器 · 计时练习` / `节拍器 · 变速练习`，不把 BPM 写进名称。

## 7. 风险与未决

- 拍号推测对真实歌曲准确率有限，必须保留“推测/不确定”口径，不能当识别结果宣传。
- 音频运行中换文件会触发内部停止/重启；自动记录必须识别为重启，不能误记半场。
- 计时与变速同时开启时，双轨进度条的视觉密度需要真机确认。
- 色块闪动在 32 拍、高 BPM 下可能过密，必要时降低亮度或缩短脉冲。
- 自动记录会进入备份与 WebDAV 同步，和手动记录同源，需要确认用户接受。
