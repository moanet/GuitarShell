## 1. 目标

- 删除“首次使用请允许麦克风”静态提示，不让静态文案占用实时反馈位置。
- 实时反馈（“拨动琴弦…” / “偏低” / “偏高” / “音准完美！”）回到指针仪表盘上方、频率下方。
- “标准调弦 / A4”标题继续下压，贴近 72px 大读数。
- “设置 + 开始调音”动作行紧跟弦位行，间距与音分曲线到弦位行一致。
- 指针仪表盘仍保持在屏幕视觉中心。

## 2. 非目标

- 不改 YIN 检测、频率平滑、音分曲线、试听时长、提示音 / 震动触发条件。
- 不改调弦预设、自定义调弦数据、A4 校准逻辑与设置弹层内部结构。
- 不改节拍器、书架、练习记录或全局设置。
- 不打 tag、不创建 GitHub Release；本版只提交并推送 `main`。
