## 1. 目标

- 书架卡片上的文件名不再被系统文本选择命中，长按不弹“复制 / 分享 / 全选”等原生菜单。
- 长按书架卡片约 500ms 进入批量管理，并选中被长按的那一份乐谱。
- 保留现有“管理 / 完成”显式入口；普通短按仍进入阅读页。
- 不重做已有批量管理能力：多选、全选、批量标签、批量删除继续复用。

## 2. 非目标

- 不改数据库、备份、云同步、封面缓存与阅读进度结构。
- 不改卡片尺寸、封面比例、标题两行截断、标签徽标与分组网格。
- 不新增长按编辑、长按删除、拖拽排序、滑动操作或右键菜单。
- 不引入手势库；只使用浏览器原生 Pointer Events。
- 不改阅读器正文、文本谱、设置输入框等区域的文字选择能力。
- 不在本版处理练习记录页；该工作留给 `0.1.26`。

## 3. 交互与实现

### 3.1 禁用书架文字选择

- `.score-card` 增加 `user-select: none`、`-webkit-user-select: none` 与 `-webkit-touch-callout: none`，覆盖标题、元信息与标签区域。
- 卡片上的 `contextmenu` 事件统一 `preventDefault()`，避免 Android WebView 弹原生文本菜单。
- 禁用范围只限书架卡片；阅读器文本、设置输入框、标签弹窗输入框保持可选中 / 可编辑。
- `title` 属性保留，桌面端悬停仍可看完整文件名。

### 3.2 长按进入批量管理

- 仅普通模式响应长按；已经处于管理态时，长按不新增行为，短按继续切换选中。
- `pointerdown` 后启动 500ms 计时器；只接受主指针与鼠标左键。
- 手指 / 鼠标移动超过 10px、`pointerup`、`pointercancel`、`pointerleave` 或书架滚动时取消计时器。
- 计时器触发时：
  - 把被长按乐谱加入 `selectedIds`；
  - 调用现有 `setManageMode(true)`；
  - 重绘后该卡片显示选中态，底部批量条显示“已选 1 份”。
- 长按触发后设置短暂点击抑制窗口；松手产生的 `click` 不得进入阅读页，也不得立刻把刚选中的卡片取消。
- 普通短按保持原行为：普通模式打开阅读页，管理态切换选中。
- 卡片右上编辑按钮不参与长按手势；点击编辑按钮仍打开编辑弹窗。

### 3.3 生命周期与清理

- 重绘书架、切 Tab、退出组件时清除长按计时器与按压上下文，避免旧卡片计时器误触发。
- 卡片重绘后事件重新绑定，不依赖旧 DOM 节点。
- 长按进入管理只触发一次；持续按住不重复调用 `setManageMode`。

## 6. 风险

- **长按与滚动冲突**：必须在移动 / 滚动时可靠取消，不能把正常滚动识别成长按。
- **长按与点击冲突**：`setManageMode(true)` 会重绘书架，松手 click 可能落到新卡片；需要时间窗抑制，不能依赖旧节点标记。
- **WebView 原生菜单**：仅 `user-select:none` 在部分 WebView 上可能不足，需同时拦截 `contextmenu` 并在真机确认。
- **选择范围过宽**：禁选只作用于书架卡片，不能污染阅读器、输入框和弹窗。
- **重绘计时器泄漏**：旧卡片被替换后若计时器未清理，可能在别的界面误触发管理态。
