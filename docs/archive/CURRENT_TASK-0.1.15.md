# CURRENT_TASK — 0.1.15 分享卡定稿与双自定义背景

> 状态：已发布。六套默认背景与页脚蜗牛排版定稿；自定义背景从 `6+1` 扩为 `6+2`，两套各自一张图、各自压暗。
> 版本：`0.1.15` / `versionCode 121`；提交 `c20e9f4`，tag `v0.1.15`。
> 原则：只动分享卡与其背景设置，不改读谱、书架、节拍器、调音器、练习记录与云同步。

## 1. 本轮范围

- 六套分享卡背景保持不对称编辑排版：左侧超大时长、右侧两行统计、下方曲名、底部细线加格言。
- 页脚保留当前定稿蜗牛：细线同心壳、不填色、无拖尾、头部左侧无竖线、触角微弯；中央不再放音孔。
- 背景色板从 `6 默认 + 1 自定义` 扩为 `6 默认 + 2 自定义`，总数 8 个；每套自定义背景仍只承载一张图。
- 两套自定义背景各自保存图片、裁切结果与压暗值，切换时互不覆盖。
- 自定义压暗范围从 `60%–90%` 放宽到 `0%–90%`，默认 `30%`；`0` 必须被当作有效值。
- 保持现有分享 / 保存链路与六套默认背景参数不变。

## 2. 已改文件

- `js/services/share-card.js`：支持 `custom` / `custom2` 两套自定义背景；压暗默认 30%，下限 0。
- `js/services/share-bg.js`：双槽位资产指针、独立压暗值、独立保存 / 读取 / 移除；第二套使用 `gs_share_bg_asset_2`、`gs_share_bg_dim_2`。
- `js/components/share-preview.js`：色板 8 个；两个自定义入口各自缩略图、更换、移除与压暗。
- `js/components/share-bg-crop.js`：裁切确认写入指定自定义槽位。
- `js/services/storage-stats.js`：孤儿清理同时保留两套自定义背景资产。
- `tests/browser/gs_023.py`：更新 8 个色板、默认 30%、0% 下限、第二套自定义独立压暗断言。

## 5. 明确不纳入本轮

- 大库 / 长谱压力验证：用户自测，结果回来后再决定是否需要修复。
- 调音器长时稳定性：按决定不做专项，不再重复提及。
- 跨版本数据兼容专项：`1.0.0` 前不检查，按现有备份 / 恢复流程使用。
- 窄屏专项适配与可访问性专项：不列入 `0.1.X`；360 为阅读主基线，320 仅保留既有回归边界。
