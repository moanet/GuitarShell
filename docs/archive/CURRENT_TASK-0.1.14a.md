## 1. 背景与目标

`0.1.13` 的练习卡片只完成「能生成、能分享」：固定深木色、页脚一行隐私小字、原生只有系统分享、网页只有下载。讨论后确定本轮先把卡片做完整，不碰设置页。

`0.1.14a` 只解决卡片的四件事：

1. **保存到相册成为主操作**，分享降为次要操作；保存和分享后都不自动关闭预览。
2. **6 套参数化背景预设**，解决固定木色呆板的问题；自定义图片留到 `0.1.14b`。
3. **排版与字体打磨**：删掉页脚「本地练习记录 · 不上传任何数据」，改为页脚题记；数字与文字拉开层级。
4. **接入 60 条格言**（21 条 seed + 39 条新增，统一审校后全部启用）；数据层保留作者/出处，不做格言管理界面。

## 2. 本阶段范围

### 2.1 导出：保存为主，分享为次

预览浮层底栏改为：

- 原生：`保存到相册`（主，约占 2/3 宽）+ `分享`（次，约占 1/3 宽，描边按钮）。
- 网页：`保存图片`（主）+ `分享`（仅当 `navigator.canShare({ files })` 且 `navigator.share` 可用时显示，否则隐藏）。
- 去掉「取消」按钮；关闭由右上 `×`、点遮罩、返回键负责。
- 保存 / 分享成功后**不自动关闭预览**，只 toast 与按钮短暂反馈；避免用户取消分享面板后卡片消失。

保存通道：

- 原生 `ShareCard` 插件新增 `saveToGallery({ fileName, dataUrl })`。
- Android 10+：`MediaStore.Images.Media` 插入，`RELATIVE_PATH = Pictures/GuitarShell`，`IS_PENDING` 流程；不需要存储权限。
- Android 6–9（API 22–28）：申请 `WRITE_EXTERNAL_STORAGE`，写入外部 `Pictures/GuitarShell` 后 `MediaScannerConnection.scanFile`；manifest 中该权限加 `maxSdkVersion="28"`。
- 写入前校验文件名，强制 `.png`，清洗非法字符；解码 base64 失败、磁盘不足、权限拒绝都返回明确错误。
- 成功 toast「已保存到相册 Pictures/GuitarShell」；失败 toast「保存失败：<原因>」，预览保持可操作。
- 分享继续复用现有 `share({ fileName, dataUrl })` + `FileProvider` + `ACTION_SEND`；用户取消分享面板不算失败。

网页保存仍走 `canvas.toBlob()` + `<a download>`；网页分享若可用则 `navigator.share({ files: [file] })`，用户取消也不报错。两条通道都不发起网络请求。

### 2.2 六套参数化背景

不做 6 套独立绘制代码，做一个 `drawBackground(ctx, preset)` + 6 组配置；每套配置包含：

- 底色渐变两端色
- 纹理类型：竖向木纹 / 纸纤维 / 亚麻织纹 / 毛呢噪点 / 金属微光 / 夜色颗粒
- 暗角强度、强调色
- 文字色组：`strong / muted / accent / line / tileFill / tileBorder`
- `light` 标记：浅色背景用深墨文字，深色背景用米白文字

预设：

| id | 名称 | 基调 | 文字 |
|---|---|---|---|
| `walnut` | 深胡桃木 | 现版深木底，默认 | 米白 |
| `oak` | 浅橡木 | 暖浅木色、细直纹 | 深墨 |
| `linen` | 亚麻纸 | 暖纸底、纤维颗粒 | 深墨 |
| `felt` | 墨绿台呢 | 深绿、细毛呢噪点 | 米白 |
| `brass` | 炭黑黄铜 | 近黑底、黄铜微光 | 米白 |
| `midnight` | 午夜蓝 | 深蓝黑、夜色颗粒 | 米白 |

- 默认 `walnut`；用户选中的背景写 `localStorage gs_share_bg`，下次打开沿用。
- **当前六套视觉为暂定**：纹理强度、配色和色板样式后续还会继续调整；先保证参数化结构、持久化和对比度验收不回退。
- `walnut` 保持现版渐变 + 暗角，不重新加竖向木纹；`oak` 才用细直木纹。其余纹理保持低对比，不能抢字。
- 预览浮层在曲名开关下方加一行 6 个小色板（28px 圆形，选中加暖色描边），文案只写「背景」。
- 本阶段不做相册自定义、不做跟随主题、不做背景上传。
- 每套预设都要在 1080×1440 下检查文字对比度与木纹/颗粒是否抢字；浅色预设必须换成深墨文字组。

- 格言是页脚装饰，不做视觉重点；始终显示，不随曲名开关隐藏。
