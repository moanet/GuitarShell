# Guitar Shell 发布检查清单

> 每次正式发版复用的手工检查表。历史通过情况与证据写进 `CHANGELOG.md`，不写回本文件。
> 当前迭代范围见 `CURRENT_TASK.md`；长期边界与风险见 `TASK.md`。
> 版本号与发布规则以 [VERSIONING.md](VERSIONING.md) 为准；本清单只负责执行检查，冲突时以 VERSIONING 为准。

## 1. 真机测试协作约定

- 开始真机操作前，助手明确说「开始真机测试，请先别动设备」；未说明时用户可正常使用。
- 屏幕长时间不动不代表结束；构建、等 ADB、读日志都可能有空档，以明确结束说明为准。
- 需要用户接管（登录、验证码、系统授权、确认）时单独请求；未收到请求不要操作设备。
- 全部结束后明确说「真机测试结束，设备还给你」。
- 测试图片只放系统相簿，不通过「导入」进书架；误导入要在结束前删除并核对乐谱数量。
- 用户误操作不追责；先检查数据与资产，能清理则清理，并把意外路径记为额外验证。

## 2. 发布前静态检查

- [ ] `CURRENT_TASK.md` 的目标、边界、验收项已覆盖；未完成项已移出本版。
- [ ] 四处核心同步：`package.json`、`js/services/version.js`、`sw.js`、`android/app/build.gradle`；`package-lock.json` 与 README 版本徽标做一致性检查。
- [ ] `versionCode` 递增，`versionName` 与发布版本一致。

- [ ] `npm run check` 通过，JS 文件数、SW 缓存与版本号一致。
- [ ] `www/`、`dist/`、keystore、`keystore.properties`、`*.jks`、`*.keystore` 均未进入 Git。
- [ ] README 引用的截图均存在；仓库只保留批准的实机截图，不含私人手机截图。
- [ ] `git status` 只有预期改动，没有临时测试谱、截图或日志。

## 3. 浏览器回归

### 3.1 分层原则

- **L0 静态门禁（每次改代码都跑）**：`npm run check`；改到 Python 测试脚本时补 `py_compile`。几十秒内完成，不替代浏览器回归。
- **L1 当前任务回归（每次任务必跑）**：只跑与本次改动直接相关的 **1 个主脚本，最多 2 个**。超过 2 个说明改动跨了多个模块，直接升级到 L2，不再逐个堆。
- **L2 发版前冒烟（每个正式版跑一次）**：默认跑 `gs_022`、`gs_023`、`gs_018` 三个；本版若动过云同步或相册，再补 `gs_021` / `gs_019`；本版若动过图标或书架搜索行，再补 `gs_024`；本版若动过节拍器主界面或 BPM 圆盘，再补 `gs_025`；本版若动过调音器，再补 `gs_026`。
- **L3 全量回归（不随普通任务跑）**：`gs_015`–`gs_026` 全部执行。只在共享底座大改、版本冻结、季度巡检或 L2 出现无法定位的回归时使用。

### 3.2 L1 改动面映射

每次任务只选命中当前改动的那一行，不是把整张表跑一遍。

| 改动面 | L1 主脚本 | 说明 |
| --- | --- | --- |
| 分享卡 / 设置 / 存储 / 缓存 | `gs_023` | 全局设置五分区、分享卡六套背景、保存 / 分享 mock |
| 图标 / 书架搜索行 | `gs_024` | Emoji 清理、线性 SVG、搜索行 360 / 320 收口 |
| 读谱 / 文本谱 / 禅定 / 封面 / DB v4 | `gs_022` | 书架、TXT / MD / CHO、桌面快捷键、数据层 |
| UI 层级 / 手势 / 阅读工具栏 | `gs_018` | 返回层级栈、双指缩放、脏确认、工具栏 |
| PDF 拆分 / 页段输入 | `gs_016` | 拆分、缩略图、非法页段、返回层级 |
| 相册导入 / 20 张上限 | `gs_019` | Photo Picker、Web 回退、超限拦截 |
| 云同步 / WebDAV 写入 | `gs_015` + `gs_021` | 超时 / 取消 / 重试；MOVE / PUT / 下载回退 |
| 节拍器设置面板 | `gs_020` | 五卡、拍号、细分、定时档、深浅色 |
| 节拍器主界面 / BPM 圆盘 | `gs_025` | 非线性映射、锚点拖动、刻度标签、中心输入 |
| 调音器 / 调弦预设 / A4 收纳 | `gs_026` | 状态条、弦位行、预设与自定义、点弦试听 |

补充规则：

- 命中 1 行 → 只跑该行脚本。
- 命中 2 行 → 最多跑这 2 个脚本。
- 命中 3 行及以上 → 视为跨模块改动，直接跑 L2 的 3 个冒烟脚本。
- 改动 `db.js` / `backup.js` / `webdav.js` / `ui-layer.js` / `audio.js` / `version.js` / `sw.js` 等共享层 → 至少跑 L2；涉及数据迁移或缓存策略时直接升级 L3。
- 如果只改分享卡，L1 只跑 `gs_023`。

### 3.3 宽度与主题

- [ ] 360 宽：所有 L1 / L2 / L3 默认都在 360 下跑。
- [ ] 320 宽：只在改了布局、间距、字号、抽屉、工具栏、卡片比例时补跑；不再作为每个版本的固定全量项。
- [ ] 深色 / 浅色：页面、系统栏、启动图、图标均正常。
- [ ] 控制台无未处理异常，无旧缓存版本残留。
- [ ] 触屏与鼠标路径都覆盖：点击、长按、拖拽、滚轮、双指缩放、右滑关闭。

### 3.4 执行记录

- [ ] 记录本版跑了哪些脚本、通过数、失败项与是否升级到下一层。
- [ ] 全量回归只在触发条件成立时执行，不把“没跑全量”当成缺陷。

## 4. 功能冒烟

### 4.1 导入与书架

- [ ] 导入 PDF / 图片，书架出卡，封面与类型正确。
- [ ] 相簿选择单张、5 张、20 张；第 21 张被系统拦截；取消无报错。
- [ ] 纯数字照片名可读；缓存文件按预期清理。
- [ ] 标签、搜索、排序、批量管理、只读徽标正常；批量标签只追加 / 移除。
- [ ] 重复内容被识别；改名同内容不重复入库。

### 4.2 读谱

- [ ] PDF / 图片谱可缩放、拖拽、存进度；重开仍在同一位置。
- [ ] 左右热区切歌，目标谱回到上次位置，不退回第一页。
- [ ] 页级书签可添加、跳转、删除；手动与自动进度不互相覆盖。
- [ ] PDF 页段拆分生成独立新卡，原谱保留；非法页段禁用，损坏 PDF 只提示。
- [ ] TXT / Markdown / ChordPro 可导入、渲染、按滚动比例存进度，当前行高亮。
- [ ] 禅定模式短按不误解锁、长按可解锁；锁定期间滚动、缩放、快捷键被拦截。
- [ ] 桌面快捷键：PageUp / PageDown、↑↓、Home / End、+/-、F、L、Space、Esc 正常。

### 4.3 节拍器

- [ ] 主与迷你节拍器不同时发声；启动新一路会停旧一路。
- [ ] 拍号、细分、音色、重音、Swing、TAP、长按步进、变速、倒计时、节奏型正常。
- [ ] 音频跟练与测速二选一；跟练控件只在跟练态可用。
- [ ] 跟练 HUD 显示文件名与速度 / 调性；测速只改 BPM，不播放音频。
- [ ] 后台 / 锁屏短时续响；播放时常亮，停止或切走后恢复熄屏。

### 4.4 调音器

- [ ] 麦克风权限正常，六弦均可识别，自动 / 手动选弦可用。
- [ ] A4 步进到 432，标准音试听正常，快速切换无爆音。
- [ ] 音分曲线随拨弦起伏；低音尾音按六弦目标折叠，不误判为二次谐音。
- [ ] 切离页面麦克风立即关闭；权限失败有提示并复位按钮。
- [ ] 调准时只提示 / 震动一次，开关可关，刷新后状态保留。

### 4.5 练习记录与分享卡

- [ ] 打卡后记录页自动刷新，显示时长、BPM、页码。
- [ ] 累计统计、趋势、TOP5、连续打卡正常。
- [ ] 卡片预览正确；曲名开关可用；保存相簿 / 网页下载成功。
- [ ] 六套预设与自定义背景可切换；3:4 裁切、拖动、双击回中正常。
- [ ] 压暗、移除、孤儿清理正常；当前使用中的背景不被误删。
- [ ] 生成全程零网络请求，不包含未授权的用户隐私信息。

### 4.6 备份、恢复与 WebDAV

- [ ] 本地备份生成 JSON；清库后恢复，乐谱 / 打卡 / 进度 / 书签完整。
- [ ] 备份包含乐谱、进度、页级书签、练习记录；不含密码保险库与主题选择。
- [ ] 恢复先校验 dataURL 再清库；中途失败不会清空旧数据。
- [ ] WebDAV「测试连接」成功；上传后另一台设备下载，书架与进度一致。
- [ ] 冲突提示正确；手动同步不自动合并；取消 / 超时 / 重试可见且不阻塞。
- [ ] MOVE 可用时原子替换；MOVE 409 / CORS 失败回退 PUT；下载可回退临时文件。
- [ ] 密码只密文保存在本机，不写 localStorage、不进备份、不打印日志。

### 4.7 设置与主题

- [ ] 五个分区顺序正确：外观、数据与备份、云同步、存储与缓存、关于。
- [ ] 主题切换后四模块同步换色，刷新后保留。
- [ ] 存储统计、配额、封面张数正确；两个清理动作不误删乐谱。
- [ ] 存储卡默认折叠；展开 / 收起与重新打开复位正常。
- [ ] 点遮罩、右滑、返回键、Esc 关闭层级正确；短横滑与纵向滚动不误关。
- [ ] 备份 / 恢复 / 清空 / 清理忙时按钮禁用并显示状态。

## 5. Android 真机

- [ ] 覆盖安装保留乐谱、进度、书签与练习记录；版本徽标正确。
- [ ] 冷启动无明显黑屏；启动图、系统栏与主题一致。
- [ ] 返回键按 `ui-layer` 层级逐层关闭；云同步中退出有确认。
- [ ] Photo Picker 可用；无存储权限弹窗；系统分享面板可拉起。
- [ ] 分享卡保存到相簿，尺寸与内容正确；取消分享后预览仍可用。
- [ ] 长时 Doze 不作必测项；有真实反馈再单独复现。
- [ ] Android 12 及以下不做真机验证；SAF 回退代码保留，不作为验收缺口。

## 6. 构建与产物校验

- [ ] `npm run apk:release` 构建成功。
- [ ] 产物位于 `android/app/build/outputs/apk/release/app-release.apk`。
- [ ] `aapt` 校验包名 `com.guitarshell`、`versionCode`、`versionName`。
- [ ] `apksigner` 校验 v1 / v2 签名通过；证书 SHA-256 与本项目 release 证书一致。
- [ ] 记录最终 APK 字节数、SHA-256 与本地路径。
- [ ] 最终 APK 复制/命名为 `dist/GuitarShell-<版本号>.apk`；`0.1.26` 的 `-release` 命名为历史例外。
- [ ] 用最终产物（不是中间构建）完成最后一轮真机关键路径确认。

## 7. 发布与发布后

- [ ] 提交并推送 `main`；提交信息按 `feat:` / `fix:` / `docs:` / `chore:` 规范。
- [ ] 先建 draft Release（`tag_name` 为 `vX.Y.Z`，指向版本提交）；上传签名 APK，用 API 核对 asset 名称、大小、digest，不下载。
- [ ] asset 成功后再创建 / 推送 tag `vX.Y.Z`，publish draft；Release 标题严格为 `vX.Y.Z`，不加副标题。
- [ ] Release notes 说明本版内容；被并入的未发布版本单独成段说明。
- [ ] 上传或下载超时按 `docs/VERSIONING.md` 第 5 节处理：立即报告并停止，不重试、不下载校验；停在 draft，不 publish、不打 tag。
- [ ] README 下载入口、版本徽标、界面预览按需更新；目录变更同步 `项目目录结构.txt`。
- [ ] `CHANGELOG.md` 补齐改动、验收、APK 校验与 Release ID / asset ID。
- [ ] `TASK.md` 只更新当前基线、活跃待办与开放风险，不追加版本叙述。
- [ ] `CURRENT_TASK.md` 归档为 `docs/archive/CURRENT_TASK-<版本>.md`。
- [ ] CI 的 `static-checks` / `build` / `deploy` 成功；Pages 已部署新版本。
- [ ] 清理临时测试文件、测试谱与临时截图；`git status` 干净。

## 8. 测试矩阵

| 维度 | 必测值 | 说明 |
| --- | --- | --- |
| Web 宽度 | 360 必测；320 仅布局改动时补测 | 360 为阅读主基线；320 只保留既有边界，不做窄屏专项 |
| 主题 | 深色 / 浅色 | 含启动图、系统栏、图标、Canvas |
| 平台 | 网页 / Android 壳 | 原生能力只在壳内验证 |
| 安装方式 | 覆盖安装 | 保留旧数据；全新安装按需 |
| 输入方式 | 触屏 / 鼠标 | 手势、滚轮、双指缩放 |
| 网络 | 在线 / 离线 | PWA 缓存与 WebDAV 错误路径 |
| 屏幕 | 手机竖屏为主 | 桌面宽度按需抽查 |
