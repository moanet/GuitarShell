## 2. 每页统一流程

1. 归档上一份 `CURRENT_TASK.md`，新建本页任务书；写清目标、非目标、范围、已锁定交互、验收和状态。
2. **P1 只读审计**：360/320、深/浅截图与计算样式对照规范，先出差异表；不改代码。
3. **P2 视觉收口**：只改本页触达的间距、字号、按钮、状态和 44 热区；不新增中间值，不顺手改其他页。
4. **P3 自动化**：`npm run check` + 本页浏览器回归；需要时补断言和 `tests/browser/README.md`。
5. **P4 真机抽验**：仅在需要时构建 dev APK；结束后恢复设备、明确交还。
6. **收尾**：更新 `CHANGELOG.md`、`TASK.md`，归档任务书；小步提交并推 `dev`，不 bump 版本。

## 3. 边界

- 规范里的 v1.2 实验项（调音器指针/去光晕、Tab 胶囊 A/B、14/16 圆角合并等）不混入本轮。
- 阅读器只做触达收口，不把浮动工具组强行并入五段工具栏；是否改版留到阅读器专项。
- 全局外壳只做一致性和触控修正，不改品牌字号、Tab 选中态和头部总高。
- 每页任务书都必须有可验收项；没有验收口径就不开工。
