> 适用范围：应用内所有页面、弹层、表单、卡片、状态和全局头部。

发生冲突时按以下顺序取准：

1. 已验收真机效果

5. 历史截图（只作参考，不反向定义新规则）

## 0. 本版决策摘要

`v1.1` 不是全量重做，也不是四个区的信息架构重排。它只做四件事：冻结基线、统一外壳、统一通用组件、给样板区一个可执行的语法。

本版拍板七个决策，并把“设置弹层 + 节拍器”样板写成可复用的默认值（D7）：

| 编号 | 决策 | 结论 |
|---|---|---|
| D1 | 头部 | 保留当前品牌 18 / Tab 16 / 版本胶囊 11 / 图标描边 1.8 / 品牌图标 26（例外）；只补 44 热区，不改字号和描边 |
| D2 | 页面宽度 | 仪器页 500、设置抽屉 360 / 底弹 400、乐谱书架 1400 且最多 6 列、阅读器全宽；不做全局 500 |
| D3 | 调音器 | v1.1 继续冻结当前仪表 80、频差条 52、指针 4px 红色；新指针和去光晕推迟到 v1.2 单独实验 |
| D4 | 设置入口 | 头部齿轮是图标按钮；页面底部“设置”是文字动作按钮；阅读器浮动工具组不叫设置按钮 |
| D5 | 字号与圆角 | 字号七档，中文整句最低 11；圆角六档加一个工具栏/仪器细条例外，不开放中间值 |
| D6 | 可访问性范围 | 焦点环新组件必须、存量触达即补；`prefers-reduced-motion` 新组件优先；120% 字体与 320 宽不作为 v1.1 验收门槛，v1.2 再评估 |
| D7 | 样板结论 | 设置弹层 + 节拍器 P7 真机通过；实际值写入 5.2，偏差关闭项写入 7.1；**不自动推广**到调音器、乐谱、记录、阅读器 |
| D8 | 关闭路径 | 有固定底部“完成”的上下文设置弹层不再放头部 X，保留遮罩 / 下滑 / 返回；无底部完成的二级弹层、选择器保留 X。节拍器与调音器设置已按此收口 |

执行方式：v1.1 先作为样板区契约使用；下一块页面要推广时，先写独立任务书、按页面重做审计，不把样板值机械复制过去。不安排全应用 UI 大扫除。

## 1. 设计原则

### 1.1 一套骨架，两套光照

深色「复古木质 · 深夜琴房」和浅色「暖纸日光 · 日间模式」是同一套界面的两种光照，不是两个设计。

布局、尺寸、圆角、层级、图标和文案完全一致；只允许颜色、阴影和表面明度变化。切换主题不应出现位移、换行或按钮尺寸变化。

### 1.2 内容优先，一个视觉主角

每个页面只保留一个视觉主角：

- 乐谱页：谱面卡片和搜索/筛选
- 节拍器：BPM 圆盘
- 调音器：音名大读数和主仪表
- 记录：统计和趋势

主操作最多一个实心主按钮。其他动作降为描边、文字或图标。不要让装饰、阴影、标签和强调色同时抢主角色。

### 1.3 触控优先，视觉尺寸与热区分离

可见尺寸可以紧凑，但可点区域不小于 44×44。任何控件不得因为视觉小，就把热区降到 44 以下。

底部操作必须避开安全区；只靠悬停才能发现的操作，不能作为唯一入口。

### 1.4 温暖材质，克制动效

木质和纸张感来自暖棕、米白、细边框和较大圆角，不来自木纹贴图、强渐变或发光。

动效只解释状态变化，常规 120–240ms；不使用连续漂浮、呼吸光或装饰性动画。仪器状态反馈（如调音器弦位 pulse）在 v1.1 保留现状，v1.2 再评估是否改成静态。

### 1.5 统一语法，不统一内容形态

节拍器和调音器可以继续像仪表，乐谱和记录可以继续像内容和报表。统一的是外壳、标题、按钮、设置、说明文字和状态语法，不是把四个区都改成同一种卡片列表。

### 1.6 规则必须可验收

每条规范都应能判定“通过 / 不通过”：计算样式、截图、真机尺寸或可读性检查。不能验收的句子不写进正式规范。

## 2. 基础层

### 2.1 颜色角色

颜色只通过语义变量使用，不在组件中写死十六进制或新的颜色常量。允许基于已有 `--*-rgb` token 的透明度（如 `rgba(var(--primary-rgb), .18)`），但不得新造色相。深色和浅色各自维护同一组角色，角色名不变。下表只列核心角色，完整 token 以 `layout.css` 为准。

| 角色 | Token | 用途 |
|---|---|---|
| 页面底层 | `--bg0` | 页面最底层和光晕底色 |
| 卡面 | `--bg1` | 抽屉、弹层、主卡片表面 |
| 卡片默认底 | `--card-bg` | 页面内容卡、列表卡的默认底色；与 `--bg1` 分开，避免弹层和卡片混用 |
| 抬升面 | `--surface-raised` | 输入框、次级按钮、列表卡 |
| 下沉面 | `--surface-deep` | 信息条、分组底、内嵌区域 |
| 分隔线 | `--line` | 卡片边框、分区线 |
| 强分隔线 | `--line-strong` | 输入框边框、需要强调的分隔线；常规边框仍用 `--line` |
| 标题 | `--heading` | 页面标题、卡片标题、主数值 |
| 正文 | `--txt` | 主要正文和数值 |
| 次文字 | `--muted` | 说明、单位、占位 |
| 主色 | `--primary` | 主按钮、选中边框、开关开启、分段选中 |
| 强调色 | `--accent` | 焦点、活动态、短数值强调 |
| 强调文字 | `--accent-text` | 可点击文字、短强调值 |
| 成功填充 | `--success` | 已调准指针、成功图形、图表状态 |
| 成功文字 | `--success-text` | “已调准”“已完成”等文字 |
| 危险填充 | `--danger` | 破坏性按钮、错误图形；调音指针为历史例外，见 5.3 |
| 危险文字 | `--danger-text` | 删除、失败、错误说明文字 |
| 图表柱 | `--chart-bar` | 记录页柱状图常规柱 |
| 图表当前 | `--chart-current` | 记录页当前柱 |
| 主按钮文字 | `--on-primary` | 主按钮内文字和图标 |
| 阴影 | `--shadow-color` | 浮层阴影；主按钮暖色投影单独使用 `--primary-rgb`，见 2.5 |

**使用规则：**

- 文字用 `--success-text` / `--danger-text`；指针、填充、边框用 `--success` / `--danger`。不要把文字 token 拿去做 4px 指针。
- 图表使用 `--chart-bar` / `--chart-current`，不要临时用 `--accent` 代替。
- 同一状态时刻最多出现主色、强调色和一个语义色；调音指针使用 `--danger` 是历史例外，不代表页面进入危险状态。
- 正文与背景对比度不低于 4.5:1；大字号和图标不低于 3:1。深色主题的 `--muted` 用于 11px 文字和 1px 边框时，也必须实测达到 4.5:1 / 3:1。
- `--muted` 只用于次要信息，不承载关键操作；11px 辅助文字在浅色和深色下都必须实测可读。
- 渐变只用于主按钮、调音指针和 Tab 选中胶囊等“有物理感”的元素；页面底层主题光晕是已验收例外，组件内不得再新增大面积背景渐变。
- 新增颜色角色必须先补 `layout.css` 的深浅两套 token，再写进本规范；不允许在组件里直接写新的十六进制。
- `--tuner-needle` 在 v1.1 不新增；调音器继续使用当前 `--danger` 指针。v1.2 如果实验新指针，再补 token。

### 2.2 字体层级

字体栈沿用当前系统栈：

`"PingFang SC", "Microsoft YaHei", "Segoe UI", -apple-system, sans-serif`

全应用保留七档字号。数字使用 `tabular-nums`。

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 展示数字 | 72 / 34 | 700 | 调音音名 72；BPM、Hz 等大读数 34；行高 1.0–1.1 |
| 页面标题 | 20 | 700 | 设置页、全局设置抽屉标题；调音器标题 19 为已验收例外 |
| 区块标题 | 16 | 700 | 面板标题、页面内大分组、底部弹层和对话框标题 |
| 卡片标题 / 正文强调 | 14 | 600–700 | 列表项标题、表单分组标题 |
| 正文 | 14 | 400 / 600 | 主要说明、输入值；密集列表可用 13 作为旧版例外 |
| 辅助信息 | 11 | 400 | 说明、计数、单位、时间 |
| 微型标签 | 10 | 600–700 | 徽标、角标、单位、弦位号、极短状态词 |

**字号规则：**

- 中文整句最低 11px；10px 只用于单位、角标、弦位号、极短状态词，不用于整句说明、按钮标签、列表第二行。
- 品牌字 18 是全局头部例外，不计入正文层级；不要为了表格把它改成 16。
- 版本胶囊 11 是已验收值；不要改成 10。
- 禁止新增 8.5 / 9 / 9.5 / 10.5 / 11.5 / 12.5 / 13.5 / 15.5 等半像素字号。存量按 P0/P1 迁移，不在本轮全量重排。
- 字重只用 400 / 600 / 700；禁止新增 800，避免中文合成粗体发脏。存量 800 触达即改。
- 字距只给全大写英文标签；中文正文不加字距。品牌英文名的轻微字距保留。
- 中文正文行高 1.5–1.7；标题 1.2–1.35；展示数字 1.0–1.1。
- 按钮字号默认：主按钮 16，次按钮 14，文字按钮 14，工具栏按钮 11。

### 2.3 间距与页面宽度

以 4px 为基础单位。页面级间距只使用 4、8、12、16、20、24、28、32、48；6、10 只允许出现在紧凑控件内部，不作为页面分区间距。

| 场景 | 默认值 |
|---|---|
| 页面左右边距 | 乐谱 12；节拍器 16；调音器 20；记录 16；设置 12 |
| 页面区块间距 | 24；同组内 12–16 |
| 卡片间距 | 12 |
| 卡片内边距 | 紧凑卡 12；内容卡 16 |
| 控件内部横向 | 输入框 12；按钮 16–20；面板 16 |
| 图标与文字 | 小图标 6；常规 8 |

**页面最大宽按类型拆开，不做全局 500：**

| 页面类型 | 最大宽 | 说明 |
|---|---|---|
| 仪器页（节拍器 / 调音器） | 500 | 超过 500 居中，不继续拉宽 |
| 设置抽屉 / 弹层 | 360 / 400 | 抽屉 360；底部弹层 400 |
| 乐谱书架 | 内容区最大 1400，网格最多 6 列 | 手机 2 列；桌面按 `auto-fill minmax(190px, 1fr)` 自动列数，但不超过 6 列 |
| 阅读器 | 全宽 | 内容页不受 500 限制 |

### 2.4 圆角

冻结六档，另加一个工具栏/仪器细条例外。按“容器越大、圆角越大”使用，组件不得自由取中间值。

| 层级 | 半径 | 用途 |
|---|---|---|
| 胶囊 | 999 | 状态条、标签、徽标、版本胶囊、Tab 选中底 |
| 弹层 / 仪表 | 18 | 底部弹层顶部、对话框、调音主仪表 |
| 卡片 / 主按钮 | 16 | 内容卡、主操作按钮 |
| 列表卡 / 次按钮 / 文字按钮 / 提示条 | 14 | 列表卡、次按钮、文字按钮、Toast、辅助频差条 |
| 输入 / 分段 | 10 | 输入框、下拉、分段控件外框 |
| 微型元素 | 8 | 图标底、角标、图表小块 |
| 工具栏 / 图标按钮 / 仪器细条 | 12（例外） | 五段工具栏按钮、部分图标按钮、调音器频差条；不用于卡片 |

- 新增组件不得写 7 / 9 / 11 / 13 / 15 / 20 / 22 等中间值。
- 14 和 16 只差 2px，必须严格绑定组件；不要在同一类卡片里混用。
- v1.2 再评估是否把 14 合并进 16 或 12，v1.1 不强制收敛为四档。

### 2.5 阴影与层级

全应用只保留三级层级。页面内容不使用悬浮阴影。

| 层级 | 表现 | 用途 |
|---|---|---|
| 0 平面 | 无阴影，1px 边框 | 页面卡、设置卡、信息条 |
| 1 浮起 | `0 10px 30px`，使用 `--shadow-color` | 浮动菜单、提示条、迷你播放器 |
| 2 模态 | `0 24px 64px`，遮罩更深 | 底部弹层、对话框、抽屉 |

- 同一层级的阴影值必须一致，不新增黑色或棕色阴影常量。
- 主按钮固定一层暖色投影 `0 6px 16px rgba(var(--primary-rgb), .18)`；它是组件例外，不新增其他主按钮阴影值。
- 页面卡片优先用边框和底色分组，不靠阴影堆层级。

### 2.6 控件尺寸

视觉尺寸和热区分离。所有可点控件热区不小于 44×44。

| 交互层级 | 视觉尺寸 | 最小热区 | 用途 |
|---|---|---|---|
| 主操作 | 高 46，最小宽 140 | 44×44 | 每屏最多一个 |
| 次操作 | 高 44（密集行可用 36） | 44×44 | 次按钮、选择行、分段 |
| 三级图标 | 视觉 27–32 | 44×44 | 头部、行内图标按钮 |
| 紧凑图标 | 视觉 18–24 | 44×44 | 工具栏、卡片动作 |
| 文字按钮 | 高 44 | 44×44 | 低优先级动作 |
| 危险按钮 | 高 44 | 44×44 | 删除、破坏性操作 |

- 次操作默认 44；“36”只用于密集列表行，不用于主操作。
- 记录页趋势行的分享动作 32、范围分段 30 为已验收的密集行例外，只允许出现在该行，不向其他页面扩散（见 6 表）。
- 视觉 18–24 的紧凑图标，热区仍按 44 计算；不能因为图标小就缩小按钮。
- 头部设置图标视觉 27，热区 44；页面底部“设置”是 72×44 的文字动作按钮，不合并成纯图标。
- 20px 删除、28px 步进、32px 关闭都属于 P0 热区问题，必须补到 44，而不是只改视觉。

### 2.7 图标

- 使用内联 SVG 线性图标，24 单位画板，描边 1.8，圆角端点。当前实现已经是 1.8，v1.1 不改 1.7。
- 常规 18，工具栏/紧凑 20，导航和空态 24；新增图标只用 18/20/24，存量 16 作为例外，触达即改。
- 图标与文字同时出现时，图标只做识别，不替代文案；纯图标按钮必须有 `aria-label`。
- 图标颜色跟随文字角色：主要动作 `--heading` 或 `--txt`，次级 `--muted`，选中 `--accent-text`；不单独给图标上装饰色。
- 禁止 emoji 充当界面图标。新增图标先查现有图标库。

### 2.8 动效

- 常规切换 120–200ms；弹层进出 200–240ms；进度条按真实数据线性变化。
- 入场用 ease-out，出场用 ease-in；不使用弹跳、回弹和多段关键帧。
- 按钮按下可用 0.95–0.98 的缩放，持续时间不超过 120ms；同一页面最多一个元素做缩放反馈。
- 调音指针、节拍闪光、图表增长跟随数据；其余元素禁止无限循环动画。
- 仪器状态反馈（如调音器弦位 pulse）在 v1.1 保留；v1.2 再评估是否改成静态。
- `prefers-reduced-motion`：新组件优先支持；存量不作为 v1.1 迁移门槛，D6 已定范围。

## 3. 外壳组件

页头、页工具栏、设置入口、空状态、主按钮、Toast 是跨区共用外壳，不得每区重写。每个页面可以有自己的内容槽，但外壳的高度、字号、热区和状态语法必须一致。

### 3.1 全局头部

全局头部保持两行：品牌行和四个固定 Tab。

**品牌行：**

- 品牌名 18 粗体，品牌图标 26。
- 版本胶囊：字号 11，视觉高度 24（0.1.27 计算值 23.6，按 24 记录），圆角 999，边框 `--line`，文字 `--muted`；热区扩到 44×44，不改变视觉。状态为“检查中…”/“已是最新”/“可更新”，可更新时用 `--accent` 边框。必须有 `aria-label`。
- 设置按钮：视觉 27，热区 44，与右边缘至少留 12；焦点环 2px `--accent`。
- 头部总高保持 `0.1.27` 现状，v1.1 不设新值、不改动；后续 header 改造再记录实测。

**Tab 行：**

- 显示名固定为“乐谱 / 节拍器 / 调音器 / 记录”，不在页面内重排。
- 默认 16，选中使用当前暖金渐变胶囊 + 1px `--primary` 边框；v1.1 保留当前已验收样式，不改成外部稿的 14 粗体胶囊。
- 每个 Tab 热区不小于 44×44；0.1.27 可见高度为 37（16px 字号按 1.2 行高 19.2 + 16 上下内边距 + 2 边框 = 37.2），热区通过行高扩展到 44。
- 320 宽下全局 Tab 保持 16 字号、单行不换行，只作为回归边界，不重排。
- 切换 Tab 不改变页面外框位置，不出现横向滑动或整页淡入。
- 胶囊选中方案作为 v1.2 的 A/B 候选，不在 v1.1 默认执行。

### 3.2 页工具栏

页工具栏是共用外壳，不是统一样式。它提供高度、内边距、标题位置、动作槽和状态，不强制每个页面内容相同。

- 阅读器五段工具栏：高 46，圆角 12，图标 18 + 标签 11，五段等分。
- 乐谱搜索/筛选行：搜索框高 44，筛选 chips 与搜索行同一水平节奏。
- 节拍器信息条：默认透明底；只有承载分组信息时才用 `--surface-deep`。不因为统一外壳恢复外框。
- 调音器标题行：标题 19 + A4 信息，按仪器页节奏。
- 同一页面的页工具栏只允许一个主操作；其余动作用次级或图标。

### 3.3 设置入口与容器

设置入口分两类，不混用：

| 类型 | 形态 | 规格 |
|---|---|---|
| 全局设置入口 | 头部齿轮图标 | 视觉 27，热区 44；打开全局设置抽屉 |
| 页面设置动作 | 节拍器/调音器底部“设置” | 72×44，圆角 14，文字 14，可带图标；打开上下文底部弹层 |

设置容器二分：

- 全局设置 = 侧滑抽屉：宽 80vw，最大 360，全高，无圆角。
- 上下文设置 = 底部弹层：宽 90%，最大 400，顶部圆角 18。
- 同一设置任务不得同时使用两种容器；同一页面不同层级可以并存，例如底部弹层上再叠确认对话框。
- 关闭方式按容器分开：全局抽屉保持侧滑关闭；有固定底部“完成”的上下文设置弹层，关闭由底部“完成” + 点遮罩 / 下滑 / 返回键承担，头部不再放 X；无底部完成的二级弹层、选择器保留 X。
- 阅读器当前右侧浮动的是缩放、全屏、禅定锁，不是设置按钮。阅读器浮动工具组列为例外（见第 6 章），下一次阅读器改版时真机评审是否收进五段工具栏。

### 3.4 空状态

- 24 线性图标 + 14 说明文字；需要时加一个次级动作。
- 说明“为什么空、下一步做什么”，不使用大插画和彩色背景。
- 空状态上下留白 28；不同页面的空状态共用同一结构，内容可替换。

### 3.5 主按钮

- 高 46，圆角 16，最小宽 140；暖金渐变 + `--on-primary`；文字 16/700。
- 主按钮固定一层暖色投影 `0 6px 16px rgba(var(--primary-rgb), .18)`，不新增其他阴影值。
- 每屏最多一个实心主按钮；停止、删除等状态按钮不抢主按钮形态。
- 主按钮内图标 18，图标与文字间距 8。
- 底部主按钮与安全区之间至少留 12。

### 3.6 Toast

- 底部 28 + 安全区；圆角 14；字号 14（当前 13 作为已验收例外，触达即改）。
- 停留 2s；不遮挡主操作；不堆叠超过两层。
- 成功、错误、普通提示使用同一容器，只换语义色和图标，不各写一套。

- 数据卡的大数字 20–34，单位 10–11；数字和单位基线对齐，数字使用 `tabular-nums`。
- 统计三连卡在 320 宽回归边界下仍保持一行，数字 14，标签 10；空间不足时改为纵向列表，不缩到 8–9px。
- 空态使用 24 图标 + 14 说明，上下留白 28；不放大插画，不使用彩色背景。

| 容器 | 尺寸 | 规则 |
|---|---|---|
| 底部弹层 | 宽 90%，最大 400；高不超过 90% | 顶部圆角 18，标题 16 粗体；有固定底部完成时不放头部 X，内容内边距 16，底部动作 46 |

### 4.5 状态矩阵

| 状态 | 视觉 | 行为 / 文案 |
|---|---|---|
| 默认 | 使用组件默认 token | 无额外装饰 |
| 按下 | 表面加深或 0.95–0.98 缩放 | 不超过 120ms；同一页面最多一个元素缩放 |
| 选中 | `--primary` 边框 / 开关 / 分段；不用整块主色装饰 | 必须同时有文字或形状变化，不只靠颜色 |
| 禁用 | 透明度 0.45–0.55，尺寸不变 | 保留可读标签，不响应点击 |
| 焦点 | 2px `--accent` 外圈，偏移 2px | 仅键盘 / 焦点可见时出现；存量组件触达即补，不作为 v1.1 专项 |
| 加载 | 行内 18 旋转图标或骨架 | 不整页遮罩；超过 3s 给出可取消入口 |
| 错误 | `--danger-text` 图标 + 文字 | 错误原因 + 重试 / 返回；不做整块红底 |
| 成功 | `--success-text` 短提示 | 2s 后消失；调准必须同时有文字或图标 |

- 组件不得自写透明度、边框颜色和阴影魔法数字；统一使用状态 token 和组件默认值。
- 只靠颜色区分状态是不允许的；调准、错误、禁用都要有文字或形状辅助。

## 5. 页面模板

### 5.1 乐谱

- 页面左右边距 12；书架卡片网格 `auto-fill minmax(190px, 1fr)`；手机 2 列，桌面自动列数且最多 6 列。
- 内容区最大宽 1400；超过 1400 居中，不继续增加列数。
- 搜索框高 44；筛选 chips 与搜索行同一水平节奏；导入按钮 36 视觉，热区 44。
- 卡片最小 148；封面 84；标题 14；空态和批量操作使用同一底部动作区。
- 阅读器不在四个模板内：全屏内容页，工具栏保持五段 46 高，画布区域不留装饰边框；设置弹层仍按通用弹层规格。

### 5.2 节拍器

样板区，v1.1 的实际验收值为准：

- 页面左右边距 16；信息条 + 圆盘 + 底部行。信息条标签 11、数值 16、BPM 小字 10；主播放 140×46、16/700、圆角 16、暖色投影 `0 6px 16px rgba(var(--primary-rgb), .18)`。
- 圆盘最小 200；BPM 大数字 34/700、单位 10；底部“设置 / TAP”各 72×44、14/700，左右与信息条对齐 x=16，底距 28 + 安全区。
- HUD 保留 42px 占位高度，但背景透明、无边框；开关 Swing / 变速 / 倒计时时表盘不跳动。`beat-strip` 当前保留 24px 占位，只有 timer / ramp 时显示底色；只开闪光时保持透明。
- 设置入口：底部“设置”是 72×44 文字动作按钮，圆角 14；头部齿轮仍归外壳，不在本节改变。
- 上下文设置底部弹层：宽 90% / 最大 400，顶部圆角 18，标题 16/700，副标题 11，内容 padding 16 / gap 12，底部动作 46；头部不再放 X，关闭由完成 / 遮罩 / 下滑 / 返回承担。
- 弹层通用控件：卡片标题 14/700；设置标签 14；辅助 11；说明 10–11 不透明；单行选择格 36 高、圆角 10，细分双行格 44、圆角 10；输入 44、圆角 10；开关 44×26，开关行最小 44 且整行可点；勾选行 44，checkbox 20；删除图标视觉 20、热区 44。
- 弹层内不再使用 800 字重、9 圆角、13.5 字号或半像素字号；除 BPM 34 展示数字外，主界面直接可见文字收敛到 10/11/14/16。
- BPM 输入使用 `adjustPan`：键盘弹出时表盘尺寸不变、BPM 输入可见；开始按钮可能被键盘覆盖，收起键盘恢复。这是 v1.1 已验收的取舍，不要求输入时同时看到开始按钮。
- 平台已知行为：Android 返回键只收键盘时不派发 `blur`，输入仍聚焦，原生文本手柄可能停在 BPM 单位上；点输入框以外立即消失。该行为不改变布局和数据，不列为视觉偏差；若 v1.2 要彻底消除，需改 `adjustResize` 或自定义数字键盘。

### 5.3 调音器

调音器是仪器页基准，v1.1 冻结当前已验收比例：

- 页面左右边距 20；最大宽 500。
- 顺序固定：标题行 → 音名/读数 → 主仪表 → 辅助频差条 → 弦位选择器 → 动作行。
- 页面标题 19 为已验收例外；音名字母 72/700；Hz 14；音分标签 9 作为旧版例外，触达时提升到 10/11。
- 主仪表高 80，圆角 18；刻度按现有实现；指针宽 4，使用当前 `--danger`，已调准转 `--success`。
- 辅助频差条高 52，圆角 12；弦位按钮高 44、圆角 14、间距 6；选中使用 `--primary` 边框 + 下沉面，不使用暖金实心。
- “设置”72×44；“开始调音”最小 140×46；每屏只允许一个主按钮。
- 调音设置底部弹层已并入样板外壳：90% / 最大 400、顶部圆角 18、标题 16、内容 16、底部完成 46，头部不放 X；自定义调弦编辑保留返回箭头，音高选择器因无底部完成仍保留 X。
- 不再把主仪表改成 72 高、频差条 56、指针 3px；这些数值属于 v1.2 的独立实验，不进入 v1.1 默认值。
- 320 宽只作为已有回归边界，不作为设计目标；不为更窄屏或字号放大重排界面。

### 5.4 记录

- 页面左右边距 16；表单区 + 趋势区 + 日志列表。
- 表单内边距 16；输入 44；列表卡 14 圆角、12 16 内边距。
- 趋势区沿用当前统计条 + 柱状图 + TOP 列表；图表使用 `--chart-bar` / `--chart-current`。
- 记录区三段标题固定四字，顺序为“记录练习 / 练习趋势 / 练习列表”：统一 14 / 700、图标 14、图标与文字间距 6，文字起点 x=36；不用“练习记录”，避免与“练习列表”语义重复。

- 趋势行高 48；行尾“分享卡片”32 高、圆角 10、1px `--accent` 半透明边框、字号 12、图标 12，上下各留 8；视觉热区向外补到 44。

## 7. 现状偏差与迁移

以下不是“错误”，而是历史页面各自演化留下的偏差。按优先级处理：P0 影响触控或可读性，下一次改到该组件就修；P1 影响一致性，随页面改造修；P2 纯视觉细节，可最后收。样板区已关闭的项见 7.1；下表保留的是仍未关闭、或只在其他页面存在的项。

## 8. 变更流程

1. 本规范是 `v1.1`；样板已真机验收。后续修订按 `v1.2` 递增，不直接改 `v1.1` 的默认值。

6. 每条规则必须能验收；不能验收的规则不进入正式版。
7. 早期草案与外部评审意见只作为参考，版本线以 `0.1.27` 为准，不沿用 `0.1.21d / 0.1.22 / v0.2`。
